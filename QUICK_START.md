# 🚀 Quick Start - File Upload Feature

## In 30 Seconds:

1. **Open cms.html** in your web browser
2. **Click Browse button** 📁 next to any image field
3. **Select an image** from your Portfolio folder
4. **See instant preview** of your image
5. **Filename auto-fills** into the field
6. **Click Save Changes** to download updated data.json

## Done! 🎉

---

## Common Tasks:

### Add a Project with Image:
```
1. Projects tab
2. Click "Add New Project"
3. Fill in title, category, description
4. Click "📁 Browse" under "Project Image"
5. Select image file
6. See preview
7. Click Save
```

### Change Profile Photo:
```
1. Profile tab
2. Click "📁 Browse" under "Profile Image"
3. Select your new photo
4. See preview
5. Click "Save Changes"
6. Download data.json
```

### Add Achievement with Photo:
```
1. Achievements tab
2. Click "Add Achievement"
3. Fill in title & description
4. Click "📁 Browse" under "Achievement Image"
5. Select image
6. See preview
7. Click Save
```

## File Organization:

Keep all your images in the **same folder** as cms.html:

```
Portfolio Folder/
│
├── cms.html          ← Open this
├── index.html        ← Your portfolio
├── data.json         ← Updated when you save
├── cms.js            ← Backend logic
├── cms-loader.js
├── port.js
├── style.css
│
└── Images Folder/
    ├── profile.jpg        ← Put images here
    ├── p1.png
    ├── p2.png
    ├── bsu-logo.png
    └── achievement.jpg
```

## Pro Tips:

✅ **Use simple filenames**: `profile.jpg` not `My Photo (Final) (1).jpg`
✅ **Compress images**: Keep under 2MB each
✅ **Test locally**: Make sure it works before uploading to server
✅ **Backup images**: Keep copies of your original files
✅ **Use consistent formats**: Stick to JPG or PNG

---

## Troubleshooting:

**Preview not showing?**
- Try a different image format (JPG instead of PNG)
- Make sure file size is reasonable
- Check if it's a valid image file

**Filename not filling in?**
- Browser might be blocking file access
- Try a different browser
- Make sure to select a valid image

**Images not showing on portfolio?**
- Check that image files are in the portfolio folder
- Verify filenames match exactly
- Open browser developer tools (F12) to see errors
